\chapter{Designations and Abbreviations}
\begin{SingleSpace}

Following designations and abbreviations are used in this work:\par\bigskip

\begin{description}[style=multiline,leftmargin=3.5cm,labelwidth=3.2cm]

  \item[AIT-ADS]   Austrian Institute of Technology Alert Data Set
  \item[AP]        Average Precision (Area Under the Precision-Recall Curve)
  \item[AUROC]     Area Under the Receiver Operating Characteristic Curve
  \item[CAPE]      Context-Aware Prioritization Engine
  \item[CMDB]      Configuration Management Database
  \item[CVE]       Common Vulnerabilities and Exposures
  \item[EPSS]      Exploit Prediction Scoring System
  \item[ESPM]      Explainable Security Incident Prioritization Module
  \item[HIDS/NIDS] Host / Network Intrusion Detection System
  \item[RBA]       Risk-Based Alerting
  \item[SHAP]      SHapley Additive exPlanations
  \item[SIEM]      Security Information and Event Management
  \item[SOC]       Security Operations Center
  \item[XAI]       Explainable Artificial Intelligence

\end{description}
\end{SingleSpace}
